## Observations & Findings

Fine-tuning on 100 tool-heavy trajectories without enforcing the inference system prompt protocol caused severe performance degradation:
1. **Unnecessary Tool Over-Use:** The model attempted tool calls on every single direct-answer task (100% rate).
2. **Infinite Loops:** The model became stuck calling identical tools repeatedly, failing to transition from `TOOL_RESULT` to `final_answer`. 37 out of 60 tasks timed out.

---

## Hypothesis Tested

*Fine-tuning on synthetic tool traces improves tool invocation syntax, but without system prompt protocol anchor, fine-tuning causes loss of loop termination control.*

---

## Conclusion & Next Steps

Fine-tuning without system prompt causes catastrophic agent loop failure. Perform system prompt ablation study to measure recovery.
